# Backend da Pizzaria

Backend de uma aplicação para gerenciamento de uma pizzaria, desenvolvido para praticar a construção de uma API e a organização de regras de negócio.

## Tecnologias

- Node.js
- TypeScript
- API REST
- Banco de dados integrado ao backend

As tecnologias e a arquitetura podem ser aprimoradas conforme o projeto evolui.

## Funcionalidades

- Cadastro e gerenciamento de usuários;
- Cadastro e gerenciamento de produtos e sabores de pizza;
- Criação e acompanhamento de pedidos;
- Organização dos itens e valores dos pedidos;
- Autenticação e controle de acesso;
- Integração com banco de dados.
